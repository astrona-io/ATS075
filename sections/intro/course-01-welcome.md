# Welcome To The Course

This course develops the official The OpenTelemetry Collector objectives for OpenTelemetry Certified Associate (OTCA). The domain is worth 26% of the published curriculum. The certification uses a multiple-choice examination. The explanations build the reasoning needed to choose an answer, and the hands-on labs let you see each mechanism work in a real Collector.

At the end, you can read and write a Collector configuration, choose between an agent and a gateway deployment, reason about scaling and sharding, trace a signal through its pipelines and change data with processors. Technical terms and acronyms are defined when they appear. Examples use a small set of example workloads named `scout`, `probe`, `shuttle` and `drifter`. The names identify workloads only and do not change the technical meaning.

Each section begins with an introduction and learning outcomes. Each module starts with a short map, continues with teaching parts and ends with a summary. Every module has a playground, which is a clean Kubernetes cluster with a running Collector that you can explore without a task, and a graded lab, which gives you a task and checks the result on the live cluster. Each section ends with a capstone lab and a knowledge check. A final knowledge check closes the course.

Read the examples carefully, identify which component does the work and predict what changes when a condition changes. The practice questions are original and are not copied from the examination.
