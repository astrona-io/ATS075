# Introduction

This introduction explains how to use The OpenTelemetry Collector course. The domain represents 26% of OpenTelemetry Certified Associate (OTCA) and belongs to ATP015. Welcome To The Course describes the audience, learning outcomes and layout, including the playgrounds, labs and knowledge checks. Get Your Machine Ready explains the tools to install and the `astrona` commands used every day. How This Course Is Made describes author checks, contributions and the license.

The course starts with Collector configuration.
